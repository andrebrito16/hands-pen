# handpen

Desenhe no ar com a ponta do dedo indicador usando sua câmera. ✨

## Como usar

- Segure **Shift** para começar a desenhar — solte para parar.
- Aperte **Espaço** quando quiser limpar tudo e recomeçar.

Divirta-se! 🎨
